# Documento de Requisitos — SMARTTRACK

# Persona

## Marcelo — Supervisor Operacional

### Informações Gerais
- Idade: 42 anos
- Cargo: Supervisor de conservação rodoviária
- Local de atuação: Rodovias concedidas pela CCR Motiva

### Objetivos
- Monitorar áreas críticas da rodovia;
- Identificar riscos relacionados à vegetação;
- Melhorar o acionamento das equipes operacionais.

### Principais Dores
- Monitoramento manual ineficiente;
- Dificuldade na visualização rápida de ocorrências;
- Falta de centralização das informações.

---

# Requisitos Funcionais (RF)

## RF01
O sistema deve permitir login de usuários.

## RF02
O sistema deve exibir dashboard com indicadores de monitoramento.

## RF03
O sistema deve apresentar áreas críticas identificadas na rodovia.

## RF04
O sistema deve permitir visualização de alertas operacionais.

## RF05
O sistema deve permitir visualizar detalhes da vegetação monitorada.

## RF06
O sistema deve exibir status das áreas monitoradas.

## RF07
O sistema deve permitir navegação entre as telas do aplicativo.

---

# Requisitos Não Funcionais (RNF)

## RNF01
O aplicativo deve possuir interface responsiva e intuitiva.

## RNF02
O sistema deve apresentar navegação simples e objetiva.

## RNF03
O aplicativo deve possuir identidade visual consistente.

## RNF04
O sistema deve permitir futura integração com serviços de geolocalização.

## RNF05
O aplicativo deverá ser desenvolvido utilizando React Native.

---

# Restrições Técnicas

- Desenvolvimento mobile utilizando React Native;
- Prototipação desenvolvida no Figma;
- Compatibilidade com dispositivos Android e iOS;
- Dependência futura de APIs de geolocalização e monitoramento.

# Fluxo Principal da Aplicação

Login → Dashboard → Alertas → Detalhes da Vegetação
